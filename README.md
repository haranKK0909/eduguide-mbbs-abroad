# EduGuide Educational Services — MBBS Abroad Website

A modern multi-page React/Vite website concept based on the provided EduGuide reference posters.

## Pages
- Home
- About
- MBBS Abroad
- Countries
- Services
- Admission Process
- Contact

## Design direction
- Professional medical + global education visual language
- Navy / royal blue + gold gradient palette inspired by the references
- Responsive layouts
- Framer Motion reveal and 3D tilt interactions
- Three.js / React Three Fiber animated hero object
- Sticky navigation and scroll progress indicator

## Run
```bash
npm install
npm run dev
```

> The provided posters are included under `src/assets/reference-posters/` as reference material. Replace them later with clean, high-resolution brand assets/logo/photos supplied by EduGuide.
